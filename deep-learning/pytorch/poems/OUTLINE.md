### 第 1 章　语言模型是什么

**本章目标**：建立对语言模型（Language Model）的直觉认知。

| 小节 | 内容说明 |
|------|----------|
| 1.1 什么是语言模型 | 语言模型的核心任务：给一段文字打"合理度"分数，即估计概率 P(句子)。从"自动补全"到"写诗"，语言模型无处不在。 |
| 1.2 条件概率与链式法则 | 将 P(句子) 拆解为逐字的条件概率连乘：P(x₁,x₂,...,xₙ) = ∏ P(xₜ｜x₁,...,xₜ₋₁)。这一公式是所有语言模型的数学基础。 |
| 1.3 从 N-gram 到神经语言模型 | N-gram 模型的思路（只看前 N-1 个字）及其缺陷（长距离依赖、数据稀疏）；神经网络语言模型如何解决这两个问题。 |
| 1.4 字级别 vs. 词级别 | 本项目为何选择字级别（Character-level）建模：中文古诗以单字为基本单位，字表固定，无需分词。 |

### 第 2 章　词嵌入：把文字变成向量

**本章目标**：理解为什么神经网络需要将离散的字 ID 转换为连续向量，以及 Embedding 层的工作原理。

| 小节 | 内容说明 |
|------|----------|
| 2.1 独热编码的问题 | One-Hot 向量维度爆炸（词表有多大向量就多长），且无法表达字与字之间的语义相似性。 |
| 2.2 稠密词嵌入 | Embedding 层本质上是一张可学习的查找表：每个字 ID 对应一行向量，维度远小于词表大小。训练过程中，语义相近的字会自动靠近。 |
| 2.3 Embedding 层的前向传播 | 输入：整数 ID（形状 N×L）；输出：浮点向量（形状 N×L×E）。"查表"操作不涉及矩阵乘法，效率极高。 |
| 2.4 嵌入维度怎么选 | 经验规则与本项目选取 256 维的理由。维度过小欠表达、过大易过拟合。 |

### 第 3 章　循环神经网络（RNN）

**本章目标**：理解 RNN 如何通过隐藏状态（Hidden State）对序列建立记忆，掌握其计算图结构。

| 小节 | 内容说明 |
|------|----------|
| 3.1 为什么普通全连接网络不适合序列 | 全连接网络输入长度固定、无法共享不同位置的参数，处理变长序列时捉襟见肘。 |
| 3.2 RNN 的核心公式 | hₜ = tanh(W_h · hₜ₋₁ + W_x · xₜ + b)。图示隐藏状态如何在时间步之间流动，形成"记忆"链条。 |
| 3.3 按时间展开（Unrolling） | 将循环结构展开为一条计算图，直观展示 RNN 在序列上的前向传播过程。 |
| 3.4 多层堆叠 RNN | 深层 RNN：上一层的隐藏状态作为下一层的输入。层数越多，能捕捉越抽象的序列模式。 |
| 3.5 梯度消失与梯度爆炸 | 时间步越长，梯度在反向传播中越容易趋近 0（消失）或无穷大（爆炸）。这是 RNN 的经典痛点，引出第 4 章的应对方案。 |

### 第 4 章　训练原理

**本章目标**：从损失函数到参数更新，完整描述语言模型的训练过程，并介绍两个关键的稳定训练技巧。

| 小节 | 内容说明 |
|------|----------|
| 4.1 交叉熵损失 | 语言模型的训练目标：最大化真实字的预测概率，等价于最小化交叉熵 loss = -log P(yₜ｜x₁..xₜ)。PyTorch 中 `CrossEntropyLoss` 内部集成了 softmax。 |
| 4.2 随时间反向传播（BPTT） | 梯度如何沿时间步反向流动；展示计算图中梯度链路，说明为什么长序列训练困难。 |
| 4.3 梯度裁剪 | 应对梯度爆炸的简单有效方法：当全局梯度 L2 范数超过阈值时，等比例缩小所有梯度。公式与 PyTorch 实现 `clip_grad_norm_`。 |
| 4.4 Dropout 正则化 | 训练时随机将部分神经元输出置零，迫使网络学习冗余表示，从而缓解过拟合。本项目在层间和输出层前分别使用 Dropout。 |
| 4.5 Adam 优化器 | 为什么 Adam 比 SGD 更适合语言模型训练：自适应学习率、动量估计、对稀疏梯度友好。 |

### 第 5 章　文本生成与推理策略

**本章目标**：理解训练好的模型如何被用于生成新文本，重点讲解自回归生成、隐藏状态传递和温度采样。

| 小节 | 内容说明 |
|------|----------|
| 5.1 自回归生成 | 模型每次只预测一个字，将预测结果反馈为下一步输入，循环生成完整诗句。与训练时"一次输入整段序列"的区别。 |
| 5.2 为什么要传递隐藏状态 | 若每步生成都重置 hidden 为 None，模型对"已经写了什么"毫无记忆。持续传递 hidden 才能保证生成的连贯性——这也是本项目相对原始代码修复的关键 bug。 |
| 5.3 贪心解码 vs. 随机采样 | 贪心（argmax）每次取概率最高的字，生成结果确定但缺乏变化；随机采样（multinomial）按概率分布抽取，同一起始字每次能生成不同的诗。 |
| 5.4 温度（Temperature）采样 | 用系数 T 缩放 logits 再做 softmax：T<1 让分布变尖（更"保守"），T>1 让分布变平（更"大胆"）。可视化不同温度对概率分布的影响。 |
